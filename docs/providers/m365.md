# Microsoft 365 (Microsoft Graph)

Autor: **Ing. Heri Espinosa**

MC Send Notify envía con `POST /users/{remitente}/sendMail` en formato MIME, para conservar `List-Unsubscribe` y el `Message-ID`. El token se obtiene con el flujo _client credentials_ de una aplicación registrada en Microsoft Entra ID.

> **Cuándo usarlo:** comunicaciones de volumen bajo o medio desde buzones corporativos. Exchange Online limita cada buzón a **30 mensajes por minuto** y **10.000 destinatarios al día**, y prohíbe el envío masivo a destinatarios externos. Para newsletters grandes, usa SES o Resend.

## 1. Registrar la aplicación

1. En el [Centro de administración de Microsoft Entra](https://entra.microsoft.com) → **Aplicaciones** → **Registros de aplicaciones** → **Nuevo registro**.
   - **Nombre:** `MC Send Notify`. Cuentas de este directorio únicamente. Sin URI de redirección.
2. Anota el **Id. de aplicación (cliente)** y el **Id. de directorio (inquilino)**.
3. **Certificados y secretos** → **Nuevo secreto de cliente**. Copia el **valor** (solo se muestra una vez) y anota su caducidad: hay que renovarlo antes.

## 2. Limitar los buzones con RBAC for Applications (recomendado)

El permiso de aplicación `Mail.Send` concedido en Entra permite enviar **como cualquier buzón del inquilino**. Para restringirlo a los buzones remitentes, usa **RBAC for Applications** de Exchange Online.

1. **Sin consentimiento en Entra:** no concedas (o retira) el consentimiento de administrador de `Mail.Send` en Entra. Los permisos de Entra y de RBAC se suman, así que con el de Entra concedido el ámbito no tendría efecto.
2. **Grupo de remitentes:** crea un grupo de seguridad habilitado para correo (por ejemplo `mcsn-remitentes@multicomputos.com`) con los buzones que podrán enviar.
3. **Asignación en Exchange Online PowerShell:**

```powershell
Connect-ExchangeOnline

# Entidad de servicio de la aplicación en Exchange (ObjectId de la "Aplicación empresarial")
New-ServicePrincipal -AppId <clientId> -ObjectId <objectIdAplicacionEmpresarial> -DisplayName "MC Send Notify"

# Ámbito: solo los miembros del grupo de remitentes
$grupo = (Get-DistributionGroup mcsn-remitentes@multicomputos.com).DistinguishedName
New-ManagementScope -Name "MCSN remitentes" -RecipientRestrictionFilter "MemberOfGroup -eq '$grupo'"

# Rol de envío limitado a ese ámbito
New-ManagementRoleAssignment -App <clientId> -Role "Application Mail.Send" -CustomResourceScope "MCSN remitentes"

# Comprobación: InScope = True para un remitente, False para otro buzón
Test-ServicePrincipalAuthorization -Identity <clientId> -Resource notificaciones@multicomputos.com
```

La propagación puede tardar entre 30 minutos y 2 horas.

## 3. Configurar el proveedor en MC Send Notify

En **Configuración › Proveedores de correo › Nuevo proveedor**, tipo **Microsoft 365**:

| Campo              | Valor                                                         |
| ------------------ | ------------------------------------------------------------- |
| Id. de inquilino   | Id. de directorio o dominio (`multicomputos.onmicrosoft.com`) |
| Id. de aplicación  | Id. de aplicación (cliente)                                   |
| Secreto de cliente | Valor del secreto                                             |
| Envíos por segundo | `0,5` (30 por minuto, el límite del buzón)                    |
| Máximo al día      | `10000`                                                       |

Pulsa **Probar conexión**. Después crea los **remitentes** con los buzones del grupo: el `fromEmail` debe ser uno de ellos.

## 4. Eventos de entrega

Graph no notifica entregas, rebotes ni quejas. MC Send Notify registra aperturas, clics, descargas y bajas con su propio seguimiento. Los rebotes llegan como NDR al buzón remitente: revísalos o redirígelos a quien gestione la calidad de las listas.

## 5. Problemas frecuentes

| Error                         | Causa                                   | Solución                                                 |
| ----------------------------- | --------------------------------------- | -------------------------------------------------------- |
| `AUTH` al probar la conexión  | Secreto caducado o inquilino incorrecto | Renovar el secreto y actualizar el proveedor             |
| `ErrorAccessDenied` al enviar | El buzón no está en el ámbito de RBAC   | Añadirlo al grupo de remitentes y esperar la propagación |
| `MailboxConcurrency` / 429    | Se superaron los 30 por minuto          | Bajar **Envíos por segundo** a `0,5` o menos             |
| Correos en spam               | Faltan SPF, DKIM o DMARC del dominio    | Ver la [guía DNS](dns.md)                                |
